# Игра «Жизнь» (Conway's Game of Life)

Реализация клеточного автомата Джона Конвея на C# с использованием Windows Forms.

## Описание

«Жизнь» — это клеточный автомат, придуманный математиком Джоном Хортоном Конвеем в 1970 году. Игра представляет собой поле из клеток, каждая из которых может находиться в одном из двух состояний: живая или мёртвая. Состояние клеток обновляется по определённым правилам на каждом шаге (поколении).

Это не игра в привычном смысле — здесь нет игрока, который управляет процессом. Эволюция поля полностью определяется начальной расстановкой клеток и правилами.

## Правила

На каждом шаге для каждой клетки подсчитывается количество живых соседей (от 0 до 8). Затем применяются правила:

1. **Рождение:** мёртвая клетка с ровно 3 живыми соседями становится живой.
2. **Выживание:** живая клетка с 2 или 3 живыми соседями остаётся живой.
3. **Смерть от одиночества:** живая клетка с менее чем 2 живыми соседями умирает.
4. **Смерть от перенаселения:** живая клетка с более чем 3 живыми соседями умирает.

Поле «зациклено»: клетки на краях взаимодействуют с клетками на противоположной стороне (тороидальная поверхность).

## Возможности

- Настройка размера поля (до 100×100).
- Настройка начального количества живых клеток.
- Случайная расстановка клеток при инициализации.
- Пошаговая эволюция (кнопка «Шаг»).
- Автоматическая эволюция по таймеру (кнопка «Жизнь» / «Пауза»).
- Визуализация текущего и следующего поколения на двух сетках.

### Класс `Population`

Отвечает за хранение состояния поля и вычисление следующего поколения.

| Член | Назначение |
|---|---|
| `Population(int initialCount, int size)` | Создаёт поле `size × size` со случайно расставленными `initialCount` живыми клетками |
| `this[int row, int column]` | Индексатор для доступа к клетке |
| `Size` | Размер поля |
| `InitialCount` | Начальное количество живых клеток |
| `CalculateNextState()` | Возвращает новое поколение |
| `CountNeighbors(row, column)` | Считает живых соседей с учётом зацикливания |

### Класс `Form1`

Отвечает за интерфейс и взаимодействие с пользователем.

| Метод | Назначение |
|---|---|
| `initializeButton_Click` | Читает параметры, создаёт популяцию, настраивает сетки |
| `stepButton_Click` | Один шаг эволюции |
| `toggleTimerButton_Click` | Включает/выключает автоматическую эволюцию |
| `timer1_Tick` | Обработчик тика таймера |
| `AdvanceGeneration` | Отрисовка текущего и следующего поколения |
| `SetupGrids` | Настройка размеров строк и столбцов `DataGridView` |
| `RenderPopulation` | Закрашивает клетки в зависимости от состояния |
| `TryReadPositiveInt` | Проверка корректности ввода из текстового поля |
